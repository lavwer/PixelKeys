# Pixel Keys — клавиатура в стиле Pixel с буфером обмена

## Сборка
**Вариант A: Android Studio (на ПК).** File → Open → выбрать папку PixelKeys → дождаться синхронизации →
Build → Build APK(s). Файл: app/build/outputs/apk/debug/app-debug.apk

**Вариант B: GitHub.** Создать репозиторий, залить все файлы (включая папку .github), вкладка Actions → Build APK →
после зелёной галочки скачать артефакт PixelKeys-apk.

## Установка (на каждый телефон)
1. Скопировать app-debug.apk на телефон, открыть, разрешить установку из этого источника.
2. Открыть приложение Pixel Keys → «1. Включить клавиатуру» → включить переключатель.
3. «2. Выбрать Pixel Keys».

## Приватность
- В AndroidManifest.xml нет ни одного разрешения, в том числе INTERNET.
- Набранный текст не сохраняется и не логируется.
- История буфера лежит в закрытой памяти приложения, allowBackup=false.
- Записи живут 24 часа (ClipStore.TTL_MS), закреплённые остаются.
- Секретные записи от менеджеров паролей (флаг IS_SENSITIVE) не сохраняются.
