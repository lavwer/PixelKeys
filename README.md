# Pixel Keys — клавиатура в стиле Pixel с буфером обмена

## Сборка
**Вариант A: Android Studio (на ПК).** File → Open → выбрать папку PixelKeys → дождаться синхронизации →
Build → Build APK(s). Файл: app/build/outputs/apk/debug/app-debug.apk

**Вариант B: GitHub.** Создать репозиторий, залить все файлы (включая папку .github), вкладка Actions → Build APK →
после зелёной галочки скачать артефакт PixelKeys-apk.

## Установка (на каждый телефон)
1. Скопировать app-debug.apk на телефон, открыть, разрешить установку из этого источника.
2. Открыть приложение Pixel Keys → «1. Включить клавиатуру» → включить переключатель.
3. «2. Выбрать Pixel Keys».

## Приватность
- В AndroidManifest.xml нет ни одного разрешения, в том числе INTERNET.
- Набранный текст не сохраняется и не логируется.
- История буфера лежит в закрытой памяти приложения, allowBackup=false.
- Записи живут 24 часа (ClipStore.TTL_MS), закреплённые остаются.
- Секретные записи от менеджеров паролей (флаг IS_SENSITIVE) не сохраняются.

## Обновление
1. На GitHub: Add file → Upload files, перетащить содержимое новой распакованной папки (app, build.gradle.kts и т.д.), Commit changes.
2. Вкладка Actions → дождаться зелёной галочки → скачать PixelKeys-apk.
3. Установить новый APK поверх старого (удалять не нужно, если ключ подписи в проекте не менялся).

## Словари T9
words_ru.txt и words_en.txt собраны из частотных списков библиотеки wordfreq (данные: CC BY-SA 4.0,
https://github.com/rspeer/wordfreq). Словари работают офлайн, внутри приложения.

## Автоисправление
- Опечатки исправляются по пробелу, знаку препинания и Enter (учитываются соседние клавиши и частота слов).
- Слова, набранные не в той раскладке («ghbdtn» -> «привет», «руддщ» -> «hello»), исправляются по пробелу и Enter.
- Backspace сразу после исправления возвращает слово как было и запоминает его (список хранится только на телефоне).
- Не работает в полях паролей, почты, адресов, имён и там, где приложение запретило подсказки.

## Оформление, эффекты и лёгкий режим
- Новогодний режим: подробная мишура, гирлянды по краям экрана и над клавишами, ёлочные шарики, лёгкий снегопад, ёлочные цвета и пять новогодних эффектов нажатия (конфетти, снежинки, салют, звёзды, мишура).
- Вкладка «Посыпки»: сверху клавиатуры бесконечно падает снег, листья, вода (дождь, капли, пузыри) или весна (сакура, цветы, бабочки). Количество, скорость и ветер настраиваются.
- Панель подсказок: классическая капсула или чипы в стиле Material 3 (главная подсказка тональная, остальные с контуром).
- Вкладка «Пресеты»: 10 готовых сборок оформления (Pixel, Минимал, Ночь, Неон, Капсулы, Терминал, Сакура, Осень, Океан, Новый год) и 2 пресета эффектов («Искры и снег», «Тишина»).
- Приложение в стиле Material 3 Expressive: плоские тональные поверхности с крупными скруглениями, кнопки-капсулы, меняющие форму при нажатии, пружинная анимация, плавающая панель-островок.
- Голосовой ввод: узкая кнопка с микрофоном рядом с пробелом. Распознавание идёт прямо в клавиатуре (текст появляется по мере речи), без окна на весь экран. Нужно разрешение на микрофон, оно запрашивается один раз. В настройках: режим (один раз, постоянно без остановки на паузах, пока держишь кнопку), место кнопки (рядом с пробелом, вместо запятой, точки или глобуса, сверху), форма, цвет и значок.
- Обучение при первом запуске: подсвечивает кнопки приложения, переключает вкладки и показывает схему клавиатуры с пояснениями. Открывается снова внизу экрана «Управление».
- Высота клавиш: низкая, средняя, высокая, очень высокая.
- Темы: цвета из обоев (Android 12+), 9 готовых и «Свой цвет» (оттенок и насыщенность).
- «Стиль Material 3»: форма служебных клавиш, начертание букв, анимация нажатия, подсказки в углу клавиш, увеличенная буква, отступы.
- «Эффекты нажатия»: переключатель и 5 эффектов (волна, кольцо, свечение, пиксели, искры). Рисуются внутри клавиши.
- Внизу плавающий «островок» с двумя страницами: «Управление» (все настройки) и «Практика» (тренажёр: тест скорости, слова на время, тест реакции; рекорды хранятся только на телефоне).
